# Unit Test Cases: US2 - ลบวิชาจากตารางเรียนจำลอง (UI Component)

เอกสารฉบับนี้อธิบายกรณีการทดสอบ (Unit Test Cases) สำหรับส่วนติดต่อผู้ใช้ (UI) ในฟังก์ชันการลบรายวิชาออกจากตารางเรียนจำลอง

---

## รายการ Test Cases

### 1. Test Case 1 : ลบ 1 วิชาจากตารางเรียนจำลอง
* **Description:** ทดสอบการลบรายวิชา CS111 Sec 030001 ออกจากตารางเรียนจำลองเมื่อมีวิชาเรียนอยู่ในตาราง
* **Pre-conditions:** นักศึกษามีตารางเรียนจำลองในภาคการศึกษา 1/2568 และมีรายวิชาเรียน CS111 Sec 030001 อยู่บน Grid ตารางเรียน (จ.-ส. 08:00-21:00 น.)
* **Test Steps:** ผู้ใช้คลิกปุ่มลบรายวิชา CS111 Sec 030001 ออกจากตารางเรียนจำลอง
* **Expected Result:** รายวิชา CS111 Sec 030001 ถูกลบออกจากตารางเรียนจำลองสำเร็จ โดยไม่ส่งผลกระทบกับรายวิชาอื่นๆ ที่เหลืออยู่ในตาราง

---

### 2. Test Case 2 : ลบมากกว่า 1 วิชาจากตารางเรียนจำลอง
* **Description:** ทดสอบการลบรายวิชามากกว่า 1 วิชาพร้อมกันออกจากตารางเรียนจำลอง
* **Pre-conditions:** นักศึกษามีตารางเรียนจำลองในภาคการศึกษา 1/2568 โดยมีรายวิชาเรียน CS111 Sec 030001 และ MA211 Sec 020001 อยู่บนตารางเรียน
* **Test Steps:** ผู้ใช้ทำการเลือกและสั่งลบทั้งรายวิชา CS111 Sec 030001 และ MA211 Sec 020001 ออกจากตารางเรียนพร้อมกัน
* **Expected Result:** ทั้งรายวิชา CS111 Sec 030001 และ MA211 Sec 020001 ถูกลบออกจากตารางเรียนจำลองพร้อมกันอย่างถูกต้อง โดยไม่กระทบกับรายวิชาอื่นที่เหลือ

---

### 3. Test Case 3 : ลบทุกวิชาจากตารางเรียนจำลอง
* **Description:** ทดสอบการลบรายวิชาทั้งหมดออกจากตารางเรียนจำลองเพื่อเริ่มจัดตารางใหม่
* **Pre-conditions:** นักศึกษามีตารางเรียนจำลองในภาคการศึกษา 1/2568 ที่มีรายวิชาเรียนอยู่ (เช่น CS111 Sec 030001 และ MA211 Sec 020001) และต้องการลบรายวิชาทั้งหมด
* **Test Steps:** ผู้ใช้ทำคำสั่งลบรายวิชาทั้งหมดออกจากตารางเรียนจำลอง
* **Expected Result:** ตตารางเรียนจำลองกลายเป็นตารางว่างเปล่า (Empty State) บน Grid เวลา 08:00–21:00 น. พร้อมให้ผู้ใช้กดปุ่ม "+ เพิ่มวิชา" เพื่อเริ่มต้นจัดตารางเรียนใหม่ได้ทันที

---

### 4. Test Case 4 : ตารางเรียนจำลองว่างเปล่า ปุ่มลบต้องถูกปิดใช้งาน (Disabled)
* **Description:** ตรวจสอบสถานะของปุ่มลบเมื่อตารางเรียนจำลองไม่มีรายวิชาอยู่เลย
* **Pre-conditions:** ตารางเรียนจำลองอยู่ในสถานะว่างเปล่า (ไม่มีรายวิชาใดๆ อยู่ในตาราง)
* **Test Steps:** ผู้ใช้สังเกตสถานะของปุ่มลบ หรือพยายามกดคลิกที่ปุ่มลบในหน้าจอ
* **Expected Result:** ปุ่มลบจะต้องอยู่ในสถานะถูกปิดการใช้งาน (Disabled State) หรือถูกซ่อนไว้ เพื่อป้องกันไม่ให้นักศึกษาสามารถกดปุ่มลบได้เมื่อไม่มีวิชาในตาราง
