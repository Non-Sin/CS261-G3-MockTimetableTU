## หมายเหตุ

- **ผู้ทดสอบ:** UAT กำหนดให้ผู้ทดสอบเป็นสมาชิกที่ไม่ได้พัฒนา US2 แต่รอบนี้รันแบบอัตโนมัติด้วย puppeteer ตามขั้นใน UAT และเก็บหลักฐานไว้ทุกขั้น
- **ตำแหน่งปุ่มลบ:** ใน assumption ของ US2-T16 เขียนว่าปุ่มลบอยู่บน card รายวิชาในตาราง แต่หน้าเว็บจริงวางปุ่ม "ลบวิชา" "ลบที่เลือก" และ "ลบทั้งหมด" ไว้ในกล่อง "วิชาที่เพิ่มแล้ว" ใต้ตาราง ส่วนบล็อกวิชาในตารางไม่มีปุ่มลบ ข้อนี้ไม่กระทบเกณฑ์ผ่าน แต่ควรแก้ assumption ใน T16 ให้ตรงกับหน้าเว็บ
- **วิธีลบที่ใช้:** ทุกเคสลบด้วยปุ่ม "ลบวิชา" ทีละวิชาตามขั้นในเอกสาร ยังไม่ได้ใช้ "ลบที่เลือก" หรือ "ลบทั้งหมด" ใน UAT-US2-02 และ 03
- **Browser ที่สอง:** รันซ้ำทั้ง 4 เคสบน Firefox 159.0 ผลเหมือน Chrome ทุกขั้น ภาพหน้าจอของ Firefox อยู่ในไฟล์ `evidence/firefox-*.png` เช่น [หลังลบ CS180](./evidence/firefox-uat01-3-after-delete.png) และ [ปุ่ม disabled ตอนตารางว่าง](./evidence/firefox-uat04-3-buttons-disabled.png)
- **ผลดิบ:** `evidence/result.json` และ `evidence/firefox-result.json` เก็บผลรายขั้น รายการ DELETE ที่เรียก พร้อม status และ console error ซึ่งไม่มีเลย
