# รายละเอียด User Story

**US2: ลบวิชาจากตารางเรียนจำลอง** (Priority: High, Estimate: 1 point)  
**Task:** `US2-T16 Design User Acceptance Test ตาม user story details`  
**ขอบเขต:** ครอบคลุม Test case 1–4 ของ US2 (Conditions of Satisfaction)  
**นำไปใช้ใน:** `US2-T20 รัน User Acceptance Test`  

---

## 1. User Story

> **As a** นักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติของมหาวิทยาลัยธรรมศาสตร์ที่กำลังจัดตารางเรียนจำลอง  
> **I want to** ต้องการลบวิชาจากตารางเรียนจำลอง  
> **So that** ลบรายวิชาที่ต้องการออกจากตารางเรียนจำลองโดยไม่กระทบกับวิชาอื่น  

### Conditions of Satisfaction
1. สามารถลบรายวิชาออกจากตารางเรียนจำลองได้ถูกต้อง ไม่เกิด error
2. การลบวิชาที่เลือก ต้องไม่กระทบหรือทำให้ข้อมูลของวิชาอื่นในตารางสูญหายหรือเปลี่ยนแปลง
3. หากลบจนไม่เหลือวิชาในตาราง ปุ่มลบจะต้องถูกปิดใช้งาน (Disabled) หรือไม่สามารถกดลบต่อได้

---

## 2. สมมติฐาน (Assumptions)
- ปุ่มลบวิชา (หรือไอคอนลบ) จะประจำเป็นส่วนหนึ่งของ Card รายวิชาที่แสดงบนตารางเรียนจำลอง
- การลบวิชาจะดำเนินการและอัปเดตสถานะหน้าตารางบน Browser ทันที
- มีระบบป้องกันการกดลบเมื่อตารางเรียนว่างเปล่า

## 3. สภาพแวดล้อมการทดสอบ (Test Environment)

* **การรันระบบ:** รันตาม README ด้วย `docker compose up -d --build` → เปิดใช้งานที่ `http://localhost:3000`
* **Browser:** Google Chrome เวอร์ชันล่าสุด (ทดสอบซ้ำบน Safari หรือ Firefox อย่างน้อย 1 ตัว)
* **ผู้ใช้ทดสอบ:** บัญชีนักศึกษา CS ภาคปกติที่ Login ได้
* **ผู้ทดสอบ:** สมาชิกในทีมที่ไม่ได้พัฒนา US2 หรือตัวแทนผู้ใช้

### ข้อมูลทดสอบ (Test Data)
- **ชุดข้อมูล A (มีวิชาในตารางอย่างน้อย 3 วิชา ตาม seed ภาคเรียน 1/2568):**
  - วิชาที่ 1: `CS180` Introduction to User Interface and User Experience (Sec 820001 จันทร์ 13:30–16:30)
  - วิชาที่ 2: `MA211` Calculus 1 (Sec 020001 อังคาร/พฤหัส 09:30–11:00)
  - วิชาที่ 3: `CS111` Object-Oriented Concepts (Sec 030001 อังคาร/พฤหัส 11:00–12:30)
- **ชุดข้อมูล B (ตารางว่างเปล่า):** ไม่มีวิชาใดๆ อยู่ในตารางเรียนจำลอง

## 4. Test Cases

### UAT-US2-01 — ลบ 1 วิชาออกจากตารางเรียนจำลอง
**อ้างอิง:** US2 Test case ที่ 1  
**Precondition:** Login แล้ว และในตารางเรียนจำลองมีรายวิชาอยู่ตามชุดข้อมูล A (`CS180`, `MA211`, `CS111`)

| ขั้นการกระทำ | ผลที่คาดหวัง |
| :---: | :--- |
| 1 | เปิดหน้าตารางเรียนจำลอง เห็นวิชาทั้ง 3 วิชาแสดงผลอยู่บนตารางถูกต้อง |
| 2 | กดปุ่มลบวิชา `CS180` ออกจากตารางเรียน |
| 3 | วิชา `CS180` หายไปจากตารางเรียนจำลองทันที ไม่มีข้อความ Error แสดงขึ้นมา |
| 4 | ตรวจสอบวิชาที่เหลืออยู่ (`MA211` และ `CS111`) ยังคงแสดงผลในวัน เวลา และกลุ่มเรียนเดิมถูกต้อง ไม่ได้รับผลกระทบ |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง
