## ST-18 ขอบเขตเวลา: ก่อนหมดอายุ 200 หลังหมดอายุ 401

| ชั้น | สิ่งที่ตรวจ | ผล | ค่าที่ได้ (กรณีไม่ผ่าน) |
| --- | --- | --- | --- |
| API | เรียกก่อน exp 5 วินาที ได้ 200 | ✔ |  |
| API | หลัง exp ได้ 401 | ✔ |  |
| API | ถูกปฏิเสธไม่เกิน exp + 60 วินาที (clock skew เริ่มต้น) + รอบการวัด 5 วินาที | ✔ |  |

- ลำดับการเรียกหลัง exp: exp-5s → 200, exp+0s → 200, exp+5s → 200, exp+10s → 200, exp+15s → 200, exp+20s → 200, exp+25s → 200, exp+30s → 200, exp+35s → 200, exp+40s → 200, exp+45s → 200, exp+50s → 200, exp+55s → 200, exp+60s → 401
- token ถูกปฏิเสธครั้งแรกที่ exp + 60 วินาที (วัดทุก 5 วินาที)
- backend ยังรับ token หลัง exp อยู่ช่วงหนึ่ง ตรงกับ clock skew 60 วินาทีที่ NimbusJwtDecoder ตั้งไว้เป็นค่าเริ่มต้น อายุจริงจึงเป็น 3 ชั่วโมง + ไม่เกิน 60 วินาที
