## ข้อสังเกต

### Obs-01 token เดิมยังเรียก API ได้หลัง Logout

| หัวข้อ | รายละเอียด |
| --- | --- |
| พบใน | UAT-US4-02 (ตรวจเพิ่มเติมนอกขั้นใน T16) |
| อาการ | หลัง Logout เรียก `GET /api/timetable` โดยไม่มี token ได้ 401 ตามคาด แต่ถ้าใช้ token เดิมที่คัดลอกไว้ก่อน Logout ยังได้ 200 พร้อมตารางเรียน |
| ต้นเหตุ | `AuthService.logout()` ใน backend ว่างไว้ (มี comment ว่าจะเพิ่ม denylist ภายหลัง) Logout จึงล้างแค่ token ใน browser token ยังใช้ได้จนหมดอายุ 3 ชั่วโมง (`jwt.expiration-ms`) |
| ผลต่อ UAT | ไม่นับเป็น Fail เพราะผู้ใช้ทั่วไปเข้าถึงข้อมูลเดิมผ่านหน้าเว็บไม่ได้แล้ว แต่ไม่ตรงกับผลที่คาดหวังข้อ 3 ของ TC2 แบบเต็มที่ ("ข้อมูลเดิมต้องไม่สามารถเข้าถึงได้โดยอาศัยสถานะการเข้าสู่ระบบเดิม") ถ้ามีคนคัดลอก token ไปก่อน |
| เสนอ | ให้ทีมตัดสินว่าจะเพิ่ม denylist ของ token ตอน Logout (งานของ US4-T08) หรือบันทึกเป็นข้อจำกัดที่ยอมรับได้ |

## หมายเหตุ

- **ผู้ทดสอบ:** UAT กำหนดให้เป็นสมาชิกที่ไม่ได้พัฒนา US4 รอบนี้รันแบบอัตโนมัติด้วยสคริปต์ตามขั้นใน UAT พร้อมเก็บหลักฐานทุกขั้น
- **การกดปุ่มย้อนกลับ:** Login และ Logout ใช้ `router.replace` จึงไม่มีหน้าตารางค้างใน history ถ้ากดย้อนกลับทันทีหลัง Login → Logout browser จะออกจากเว็บไปเลย (ไม่เห็นข้อมูลเดิมเช่นกัน) ในการทดสอบจึงเปิดหน้าตารางอีกครั้งผ่าน `/dashboard` ก่อน Logout ให้ปุ่มย้อนกลับพากลับไปหน้าตารางได้จริง ซึ่งเป็นกรณีที่ T16 ต้องการตรวจ
- **TC3:** รอเวลาจริง 15 นาทีโดยไม่ส่ง input ใด ๆ (ไม่ขยับเมาส์ กดคีย์ เลื่อน หรือคลิก) ตรวจก่อนครบเวลา 30 วินาทีว่ายังอยู่ในระบบ เพื่อยืนยันว่าไม่ได้ Logout เร็วกว่าที่กำหนด
- **ผล Fail ของสคริปต์ใน TC3 ขั้น 3:** [run-log.txt](./evidence/run-log.txt) แสดง Fail เพราะสคริปต์เดิมกำหนดว่าต้องผ่านไป ≥ 900,000 ms พอดี แต่สคริปต์เริ่มจับเวลาหลังหน้าโหลดเสร็จ ส่วน timer ของระบบเริ่มตอนหน้า mount ซึ่งเร็วกว่าเล็กน้อย จึงวัดได้ 899.x วินาที ระบบ Logout ตรงตามค่าที่กำหนด ผู้ทดสอบจึงตัดสินเป็น Pass และแก้เกณฑ์ในสคริปต์ให้เผื่อ 2 วินาทีแล้ว รอบก่อนหน้า (Logout หลัง 900 วินาที) ก็ได้ผลเดียวกัน
- **Browser ที่สอง:** ยังไม่ได้รันบน Firefox รันได้ด้วย `BROWSER=firefox node run-uat.mjs` (ดู [uat/README.md](./uat/README.md))
- ผลดิบทุกขั้นอยู่ที่ [evidence/uat-results.json](./evidence/uat-results.json) และ log ที่ [evidence/run-log.txt](./evidence/run-log.txt)
