
# US4-T16: User Acceptance Test Specification
## User Story
**US4: ออกจากระบบช่วยวางแผนตารางเรียนจำลอง**
**As a:** นักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติของมหาวิทยาลัยธรรมศาสตร์ ที่เข้าใช้งานระบบช่วยวางแผนตารางเรียน
**I want to:** ออกจากระบบช่วยวางแผนตารางเรียนเมื่อสิ้นสุดการใช้งาน
**So that:** สามารถรักษาความปลอดภัยและความเป็นส่วนตัวของข้อมูลแผนการเรียนของตนเอง
**Priority:** Normal
**Estimate:** 1 point
**CoS อ้างอิง:** [ดู US4 ต้นฉบับ](https://trello.com/c/woLkxm6V)

## Objective
ตรวจสอบว่าผู้ใช้สามารถออกจากระบบได้สำเร็จ ระบบป้องกันการเข้าถึงข้อมูลเดิมหลัง Logout และระบบสามารถ Logout อัตโนมัติเมื่อไม่มีการใช้งานเกินระยะเวลาที่กำหนดได้

## แนวทางใช้ข้อมูลทดสอบ
- ใช้บัญชีทดสอบที่สามารถเข้าสู่ระบบได้
- กรณีทดสอบที่ 2 ต้องมีข้อมูลตารางเรียนหรือข้อมูลส่วนตัวเดิมให้ตรวจสอบหลัง Logout
- กรณีทดสอบที่ 3 ต้องยืนยันระยะเวลา Inactivity Timeout ที่ระบบกำหนดก่อนเริ่มทดสอบ

## Test Cases
### [] Test case ที่ 1: เมื่อกดปุ่ม Logout ระบบต้องออกจากระบบสำเร็จและนำทางกลับไปยังหน้า Login ทันที
**Preconditions:**
- ผู้ใช้เข้าสู่ระบบสำเร็จ

**Test Data:**
- บัญชีผู้ใช้ที่สามารถเข้าสู่ระบบได้

**Test Steps:**
1. ผู้ใช้เข้าสู่ระบบ
2. ผู้ใช้กดปุ่ม Logout
3. ผู้ใช้ตรวจสอบหน้าจอหลังจากกด Logout

**Expected Result:**
- ระบบออกจากระบบสำเร็จ
- ระบบนำทางกลับไปยังหน้า Login ทันที

### [] Test case ที่ 2: หลัง Logout เมื่อกดปุ่มย้อนกลับ ระบบต้องไม่แสดงข้อมูลตารางเรียนหรือข้อมูลส่วนตัวเดิม
**Preconditions:**
- ผู้ใช้เข้าสู่ระบบสำเร็จ
- มีข้อมูลตารางเรียนหรือข้อมูลส่วนตัวของผู้ใช้ให้ตรวจสอบ
- ผู้ใช้ออกจากระบบสำเร็จและอยู่ที่หน้า Login

**Test Data:**
- บัญชีผู้ใช้ที่เข้าสู่ระบบได้
- ข้อมูลตารางเรียนหรือข้อมูลส่วนตัวของบัญชีทดสอบ

**Test Steps:**
1. ผู้ใช้เข้าสู่ระบบและเปิดหน้าที่แสดงข้อมูลตารางเรียนหรือข้อมูลส่วนตัว
2. ผู้ใช้กด Logout
3. ผู้ใช้กดปุ่มย้อนกลับของ Browser
4. ผู้ใช้ตรวจสอบหน้าจอและข้อมูลที่แสดง

**Expected Result:**

- ระบบต้องไม่แสดงข้อมูลตารางเรียนหรือข้อมูลส่วนตัวเดิมหลัง Logout
- ระบบต้องคงอยู่ที่หน้า Login
- ข้อมูลเดิมต้องไม่สามารถเข้าถึงได้โดยอาศัยสถานะการเข้าสู่ระบบเดิม

### [] Test case ที่ 3: หากไม่มีการใช้งานเกินระยะเวลาที่กำหนด ระบบต้อง Logout ให้อัตโนมัติ
**Preconditions:**
- ผู้ใช้เข้าสู่ระบบสำเร็จ
- ทราบระยะเวลา Inactivity Timeout ที่ระบบกำหนดแล้ว

**Test Data:**
- บัญชีผู้ใช้ที่สามารถเข้าสู่ระบบได้
- ระยะเวลา Inactivity Timeout ตามการตั้งค่าจริงของระบบ

**Test Steps:**
1. ผู้ใช้เข้าสู่ระบบ
2. ผู้ใช้หยุดใช้งานระบบโดยไม่มีการกระทำใด ๆ
3. ผู้ทดสอบรอจนเกินระยะเวลา Inactivity Timeout ที่ระบบกำหนด
4. ผู้ทดสอบตรวจสอบสถานะการเข้าสู่ระบบและหน้าจอที่แสดง

**Expected Result:**
- ระบบ Logout ผู้ใช้โดยอัตโนมัติเมื่อไม่มีการใช้งานเกินระยะเวลาที่กำหนด
