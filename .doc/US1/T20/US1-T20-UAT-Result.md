## หมายเหตุ

- **ผู้ทดสอบ:** UAT ควรรันโดยสมาชิกที่ไม่ได้พัฒนา US1 รอบนี้รันแบบอัตโนมัติตามขั้นใน US1-T16 พร้อมเก็บหลักฐานทุกขั้น
- **ชื่อวิชา (TC3):** บล็อกในตารางแสดงรหัส Sec เวลา และห้อง ส่วนชื่อวิชาแสดงในรายการ "วิชาที่เพิ่มแล้ว" ใต้ตารางบนหน้าเดียวกัน จึงนับว่าผ่าน
- **ปุ่มของวิชาที่เพิ่มแล้ว (TC8):** การ์ดยังมีปุ่มแต่เปลี่ยนเป็น "เพิ่มแล้ว" สีเขียว disabled ไม่มีปุ่ม "+ เพิ่มวิชา" ตามที่ UAT กำหนด
- **แถบเวลาชนใน TC7:** Test Data ของ TC7 มีทั้ง LAS101 และ TU109 ซึ่งเวลาชนกัน แถบเตือนเวลาชนจึงขึ้นตลอดเคส เป็นพฤติกรรมที่ถูกต้องตาม TC5 ไม่กระทบผล TC7
- **Console:** มี error เดียวคือ `409 (Conflict)` จากการส่ง API ตรงใน TC8 ซึ่งเป็นผลที่คาดหวัง
- **Browser ที่สอง:** ยังไม่ได้รัน Firefox เพราะเครื่องที่รันมี Firefox 110 ซึ่งเก่าเกินกว่าที่ puppeteer รองรับ ถ้าต้องการควรรันซ้ำบน Firefox รุ่นปัจจุบัน
- **สถานะหลังรัน:** ตารางของ `6609000000` ภาค 1/2568 เหลือ 7 วิชาจาก TC7
