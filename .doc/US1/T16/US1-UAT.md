# US1-T16: User Acceptance Test Specification

## User story
US1: เพิ่มวิชาเข้าไปในตารางเรียนจำลอง

**CoS อ้างอิง:**[ดู CoS ต้นฉบับ](https://trello.com/c/HHEIoRQv)

## Objective
ตรวจสอบว่าผู้ใช้สามารถเลือกและเพิ่มรายวิชา
ลงในตารางเรียนจำลองได้ตาม Conditions of Satisfaction (CoS)

## แนวทางใช้ข้อมูลทดสอบ
-ใช้ภาคการศึกษาและชุดข้อมูลเดียวกันตลอดการทดสอบ หรือระบุ fixture ที่ใช้จริงก่อนเริ่ม UAT
-รายวิชาในหัวข้อ Preconditions คือสถานะที่ต้องจัดไว้ก่อนเริ่ม ส่วน Candidate คือวิชาที่กำลังทดสอบเพิ่ม
-สมมติฐานสำหรับกรณีที่เวลาเรียนต่อกัน: ช่วงเวลา 09:30 - 11:00 และ 11:00 - 12:30 ไม่ถือว่าชนกัน
-ประเภทกรณี: + = Positive Case , - = Negative Case, E = Edge Case

## Test Cases

### [+] Test case ที่ 1: นักศึกษาสามารถเลือกวิชาที่ต้องการจากรายการวิชาได้
**Preconditions:**
- ผู้ใช้อยู่หน้าเลือกรายวิชา
- ระบบมีข้อมูลรายวิชาอย่างน้อยหนึ่งรายการ

**Test Data:**
- รายวิชา CS101

**Test Steps:**
1. ผู้ใช้เปิดรายการรายวิชาที่สามารถเลือกได้
2. ผู้ใช้ค้นหาหรือเลื่อนหารายวิชา CS101
3. ผู้ใช้เลือกรายวิชา CS101

**Expected Result:**
- ระบบแสดงว่ารายวิชา CS101 ถูกเลือกแล้ว
- ข้อมูลรายวิชาที่เลือกตรงกับข้อมูลในรายการ

### [+]Test case ที่ 2: เมื่อเลือกวิชาแล้ว ระบบสามารถเพิ่มวิชาลงในตารางเรียนจำลองได้
**Preconditions:**
- ผู้ใช้อยู่หน้าเลือกรายวิชา
- ระบบแสดงข้อมูลรายวิชาที่เลือกแล้วอย่างน้อยหนึ่งรายการ
- รายวิชา CS101 ยังไม่อยู่ในตารางเรียนจำลอง

**Test Data:**
- รายวิชา CS101

**Test Steps:**
1. ผู้ใช้ตรวจสอบว่ารายวิชา CS101 ถูกเลือกแล้ว
2. ผู้ใช้ยืนยันการเพิ่มรายวิชา CS101 เข้าตารางเรียนจำลอง
3. ผู้ใช้เปิดดูตารางเรียนจำลอง

**Expected Result:**
- ระบบแสดงตารางเรียนจำลองที่มีวิชา CS101
- ข้อมูลรายวิชา CS101 ตรงกับข้อมูลที่เลือก

### [+]Test case ที่ 3: วิชาที่เพิ่มลงในตารางต้องแสดง รหัสวิชา ชื่อวิชา วัน และเวลาเรียน ได้ถูกต้อง
**Preconditions:**
- ผู้ใช้อยู่หน้าที่แสดงตารางเรียนจำลอง
- มีรายวิชา CS101 อยู่ในตารางเรียนจำลองแล้ว

**Test Data:**
- รหัสวิชา: CS101
- ชื่อวิชา: Discrete Structures
- วันที่เรียน: วันอังคาร และ วันพฤหัส
- เวลา: 09:30 - 11:00 ทั้งสองวัน

**Test Steps:**
1. ผู้ใช้เปิดหน้าต่างตารางเรียนจำลอง
2. ผู้ใช้ค้นหารายวิชา CS101 ในตาราง
3. ผู้ใช้ตรวจสอบรหัสวิชา ชื่อวิชา วัน และเวลาเรียน

**Expected Result:**
- ระบบแสดงรหัสวิชา CS101
- ระบบแสดงชื่อวิชา Discrete Structures
- ระบบแสดงวิชาในวันอังคาร และ วันพฤหัส
- ระบบแสดงเวลาเรียน 09:30 - 11:00 ทั้งสองวัน
