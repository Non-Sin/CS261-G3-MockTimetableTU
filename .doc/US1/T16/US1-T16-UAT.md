# US1-T16: User Acceptance Test Specification

## User story
US1: เพิ่มวิชาเข้าไปในตารางเรียนจำลอง

**CoS อ้างอิง:**[ดู CoS ต้นฉบับ](https://trello.com/c/HHEIoRQv)

## Objective
ตรวจสอบว่าผู้ใช้สามารถเลือกและเพิ่มรายวิชา
ลงในตารางเรียนจำลองได้ตาม Conditions of Satisfaction (CoS)

## แนวทางใช้ข้อมูลทดสอบ
-ใช้ภาคเรียน 1 ปีการศึกษา 2568 และข้อมูลรายวิชาตาม seed `db/seed/V20261014_2010__seed_courses_2568_1.sql` ตลอดการทดสอบ ทุกวิชา 3 หน่วยกิต
-รายวิชาในหัวข้อ Preconditions คือสถานะที่ต้องจัดไว้ก่อนเริ่ม ส่วน Candidate คือวิชาที่กำลังทดสอบเพิ่ม
-สมมติฐานสำหรับกรณีที่เวลาเรียนต่อกัน: ช่วงเวลา 09:30 - 11:00 และ 11:00 - 12:30 ไม่ถือว่าชนกัน
-วิชาที่เวลาชนยังเพิ่มลงตารางได้ แต่ระบบต้องแจ้งเตือน ส่วนหน่วยกิตเกินระบบไม่อนุญาตให้เพิ่มและไม่แสดงข้อความแจ้งเตือน ตามข้อสรุปของทีม
-ประเภทกรณี: + = Positive Case , - = Negative Case, E = Edge Case

## Test Cases

### [+] Test case ที่ 1: นักศึกษาสามารถเลือกวิชาที่ต้องการจากรายการวิชาได้
**Preconditions:**
- ผู้ใช้อยู่หน้าเลือกรายวิชา ภาคเรียน 1/2568
- ระบบมีข้อมูลรายวิชาอย่างน้อยหนึ่งรายการ

**Test Data:**
- รายวิชา CS111 Section: 030001

**Test Steps:**
1. ผู้ใช้เปิดรายการรายวิชาที่สามารถเลือกได้
2. ผู้ใช้ค้นหาหรือเลื่อนหารายวิชา CS111
3. ผู้ใช้เลือกรายวิชา CS111 Section: 030001

**Expected Result:**
- ระบบแสดงว่ารายวิชา CS111 ถูกเลือกแล้ว
- ข้อมูลรายวิชาที่เลือกตรงกับข้อมูลในรายการ

### [+]Test case ที่ 2: เมื่อเลือกวิชาแล้ว ระบบสามารถเพิ่มวิชาลงในตารางเรียนจำลองได้
**Preconditions:**
- ผู้ใช้อยู่หน้าเลือกรายวิชา
- ระบบแสดงข้อมูลรายวิชาที่เลือกแล้วอย่างน้อยหนึ่งรายการ
- รายวิชา CS111 ยังไม่อยู่ในตารางเรียนจำลอง

**Test Data:**
- รายวิชา CS111 Section: 030001

**Test Steps:**
1. ผู้ใช้ตรวจสอบว่ารายวิชา CS111 ถูกเลือกแล้ว
2. ผู้ใช้ยืนยันการเพิ่มรายวิชา CS111 เข้าตารางเรียนจำลอง
3. ผู้ใช้เปิดดูตารางเรียนจำลอง

**Expected Result:**
- ระบบแสดงตารางเรียนจำลองที่มีวิชา CS111
- ข้อมูลรายวิชา CS111 ตรงกับข้อมูลที่เลือก

### [+]Test case ที่ 3: วิชาที่เพิ่มลงในตารางต้องแสดง รหัสวิชา ชื่อวิชา วัน และเวลาเรียน ได้ถูกต้อง
**Preconditions:**
- ผู้ใช้อยู่หน้าที่แสดงตารางเรียนจำลอง
- มีรายวิชา CS111 Section: 030001 อยู่ในตารางเรียนจำลองแล้ว

**Test Data:**
- รหัสวิชา: CS111
- ชื่อวิชา: Object-Oriented Concepts
- วันที่เรียน: วันอังคาร และ วันพฤหัส
- เวลา: 11:00 - 12:30 ทั้งสองวัน

**Test Steps:**
1. ผู้ใช้เปิดหน้าต่างตารางเรียนจำลอง
2. ผู้ใช้ค้นหารายวิชา CS111 ในตาราง
3. ผู้ใช้ตรวจสอบรหัสวิชา ชื่อวิชา วัน และเวลาเรียน

**Expected Result:**
- ระบบแสดงรหัสวิชา CS111
- ระบบแสดงชื่อวิชา Object-Oriented Concepts
- ระบบแสดงวิชาในวันอังคาร และ วันพฤหัส
- ระบบแสดงเวลาเรียน 11:00 - 12:30 ทั้งสองวัน

### [+]Test case ที่ 4: หากเพิ่มวิชาที่มีเวลาเรียนไม่ตรงกับวิชาอื่น ระบบสามารถแสดงวิชานั้นในตารางได้ตามปกติ
**Preconditions:**
- ผู้ใช้อยู่หน้าเลือกวิชา
- มีวิชา CS111 Section: 030001 อยู่ในตารางแล้ว

**Test Data:**
- รหัสวิชา: CS111
- ชื่อวิชา: Object-Oriented Concepts
- วันที่เรียน: วันอังคาร และ วันพฤหัส
- เวลา: 11:00 - 12:30 ทั้งสองวัน

- รหัสวิชา: MA211
- ชื่อวิชา: Calculus 1
- วันที่เรียน: วันอังคาร และ วันพฤหัส
- เวลา: 09:30 - 11:00 ทั้งสองวัน

**Test Steps:**
1. ผู้ใช้เลือกวิชา MA211 Section: 020001
2. ผู้ใช้ยืนยันการเพิ่มรายวิชา MA211 เข้าตารางเรียนจำลอง
3. ผู้ใช้เปิดดูตารางเรียนจำลอง

**Expected Result:**

- ระบบไม่แสดงข้อความแจ้งเตือนว่าเวลาเรียนชนกัน
- รายวิชา CS111 ยังคงอยู่ในตารางเรียนจำลอง
- ระบบแสดงรหัสวิชา CS111 และ MA211
- ระบบแสดงชื่อวิชา Object-Oriented Concepts และ Calculus 1
- ระบบแสดงวิชาในวันอังคาร และ วันพฤหัส
- ระบบแสดงเวลาเรียน 09:30 - 11:00 ทั้งสองวัน และ 11:00 - 12:30 ทั้งสองวัน

### [-]Test case ที่ 5: หากเพิ่มวิชาที่มีเวลาเรียนชนกับวิชาที่อยู่ในตารางแล้ว ระบบต้องแจ้งเตือนผู้ใช้
**Preconditions:**
- ผู้ใช้อยู่หน้าเลือกวิชา
- มีวิชา TU109 Section: 780001 อยู่ในตารางแล้ว

**Test Data:**
- รหัสวิชา: TU109
- ชื่อวิชา: Innovation and Entrepreneurial Mindset
- วันที่เรียน: วันพุธ
- เวลา: 09:30 - 12:30

- รหัสวิชา: LAS101
- ชื่อวิชา: Critical Thinking, Reading, and Writing
- วันที่เรียน: วันพุธ
- เวลา: 09:30 - 12:30

**Test Steps:**
1. ผู้ใช้เลือกวิชา LAS101 Section: 780004
2. ผู้ใช้ยืนยันการเพิ่มรายวิชา LAS101 เข้าตารางเรียนจำลอง
3. ผู้ใช้ตรวจสอบข้อความแจ้งเตือนของระบบ

**Expected Result:**

- ระบบเพิ่มรายวิชา LAS101 ลงในตารางเรียนจำลองได้ (เวลาชนไม่ block การเพิ่ม)
- รายวิชา TU109 ยังคงอยู่ในตารางเรียนจำลอง
- ระบบแสดงข้อมูลของ TU109 และ LAS101 ได้ถูกต้อง และแสดงว่าทั้งสองวิชาเวลาชนกัน

### [+]Test case ที่ 6: เมื่อลองเพิ่มวิชาหลายวิชา ระบบต้องแสดงแต่ละวิชาในวันและเวลาที่ถูกต้อง
**Preconditions:**
- ผู้ใช้อยู่หน้าเลือกวิชา
- ไม่มีวิชาใด ๆ อยู่ในตารางเรียนจำลอง
- ระบบมีข้อมูลอย่างน้อย 3 วิชาที่สามารถเพิ่มได้ตามเงื่อนไข

**Test Data:**
- รหัสวิชา: MA211
- ชื่อวิชา: Calculus 1
- วันที่เรียน: วันอังคาร และ วันพฤหัส
- เวลา: 09:30 - 11:00 ทั้งสองวัน

- รหัสวิชา: CS111
- ชื่อวิชา: Object-Oriented Concepts
- วันที่เรียน: วันอังคาร และ วันพฤหัส
- เวลา: 11:00 - 12:30 ทั้งสองวัน

- รหัสวิชา: ST216
- ชื่อวิชา: Statistics for Social Science 1
- วันที่เรียน: วันอังคาร
- เวลา: 13:30 - 16:30

**Test Steps:**
1. ผู้ใช้เลือกและเพิ่มรายวิชา MA211 ลงตารางเรียนจำลอง
2. ผู้ใช้เลือกและเพิ่มรายวิชา CS111 Section: 030001 ลงตารางเรียนจำลอง
3. ผู้ใช้เลือกและเพิ่มรายวิชา ST216 ลงตารางเรียนจำลอง
4. ผู้ใช้เปิดดูตารางเรียนจำลอง

**Expected Result:**
- ระบบแสดงรายวิชา MA211, CS111 และ ST216 ครบทั้ง 3 วิชา
- MA211 แสดงในวันอังคารและวันพฤหัสบดี เวลา 09:30 - 11:00
- CS111 แสดงในวันอังคารและวันพฤหัสบดี เวลา 11:00 - 12:30
- ST216 แสดงในวันอังคาร เวลา 13:30 - 16:30
- ไม่มีรายวิชาใดหายไปหรือแสดงผิดตำแหน่ง
