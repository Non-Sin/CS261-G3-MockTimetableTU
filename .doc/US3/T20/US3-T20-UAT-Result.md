## Issue ที่พบ

### Issue-01 เมนูหลังเข้าสู่ระบบไม่ครบตาม TC7

| หัวข้อ | รายละเอียด |
| --- | --- |
| พบใน | TC7 ขั้น 2 |
| อาการ | เมนูหลักมีแค่ จัดตารางเรียนจำลอง / ดูวิชาเสรีแนะนำ / ค้นหาช่องทางขอโควตา ไม่มีเมนูหรือปุ่ม "เปลี่ยนกลุ่มเรียน" "ตรวจสอบเงื่อนไขรายวิชา" และ "บันทึกวิชาที่เคยเรียนผ่าน" |
| ที่คาดหวัง | แสดงเมนูครบ 6 ฟังก์ชันตาม CoS ข้อ 7 ของ US3 และ [US3-T16](../US3-T16.md) |
| ต้นเหตุ | `APP_SECTIONS` ใน `frontend/features/auth/components/AppNavigation.tsx` มี 3 รายการ ตาม [UI-NAVIGATION.md](../../../frontend/features/auth/UI-NAVIGATION.md): เมนูประวัติการเรียนถูกนำออก "ตามคำขอเพิ่มเติม" และการตรวจเงื่อนไขจะย้ายไปเป็น popup ตอนเพิ่มวิชา (ยังไม่ได้สร้าง) ส่วนการเปลี่ยนกลุ่มเรียนยังไม่มีใน UI |
| ทางแก้ที่เป็นไปได้ | (1) เพิ่มเมนูที่ขาดให้ครบ หรือ (2) ถ้าทีมยืนยันว่าตัดเมนูเหล่านี้ออกจาก scope ให้แก้ CoS ข้อ 7 และ T16 แล้วรัน TC7 ซ้ำ |
| แจ้ง | เจ้าของงาน US3-T07 (UI) และ PO |

## หมายเหตุ

- **TC3–4 ใช้บัญชี stub แทนการเปลี่ยนรหัสผ่านจริง:** T16 กำหนดให้เปลี่ยนรหัสผ่านบัญชี A ที่ มธ. จริง แต่รอบนี้รันด้วย profile `stub-tu` จึงใช้บัญชี F (`6609000008`) ที่จำลองว่าเปลี่ยนรหัสแล้ว (รหัสใหม่ใช้ได้ รหัสเดิมใช้ไม่ได้) บัญชีนี้มาจาก branch `test/US3-T17-run-it-ui-api` ที่ยังไม่ merge จึงนำไฟล์ `StubTuApiClient.java` จาก branch นั้นมา build ชั่วคราว แล้วคืนไฟล์เดิมหลังรัน ควรรัน TC3–4 ซ้ำเมื่อ T17 merge หรือรันกับ TU API จริงด้วยบัญชีที่เปลี่ยนรหัสได้
- **TU API จริง:** ทุก TC รันกับ stub ผลจึงยืนยันการทำงานของระบบเราตาม response ที่ TU API ตอบ แต่ไม่ได้ยืนยันการเชื่อมต่อกับ `restapi.tu.ac.th` จริง
- **ผู้ทดสอบ:** รอบนี้รันแบบอัตโนมัติตามขั้นใน T16 พร้อมเก็บหลักฐานทุกขั้น
- **Browser ที่สอง:** รันซ้ำทั้ง 8 TC บน Firefox 159 ผลเหมือน Chrome ทุกขั้น ([Login สำเร็จ](./evidence/firefox-tc1a-2-after-login.png), [Access Denied](./evidence/firefox-tc2-other-dept.png), [รหัสผิด](./evidence/firefox-tc5-wrong-password.png), [ระงับ 15 นาที](./evidence/firefox-tc6-2-locked.png), [เมนูหลัก](./evidence/firefox-tc7-1-main-menu.png))
