## Bug ที่พบ

### Bug-01 บล็อกวิชาในตารางไม่แสดงเลข Sec

| หัวข้อ | รายละเอียด |
| --- | --- |
| พบใน | UAT-US5-01 ขั้น 4 |
| อาการ | บล็อกวิชาในกล่อง "ตารางเรียนจำลอง" แสดงแค่รหัสวิชา เวลา และห้อง ไม่มีเลข Sec ทั้งบนหน้าจอและในภาพที่ส่งออก |
| ที่คาดหวัง | บล็อกวิชาแสดงรหัส **Sec** เวลา ห้อง ตาม [US5-T05](../T05/US5-DTO%20&%20API%20Spec.md) (ตาราง "ส่วนในภาพ") และ UI Prototype ที่มีป้าย Sec บนบล็อก |
| ต้นเหตุ | บล็อกวิชาใน `frontend/features/timetable/components/TimetableGrid.tsx` ของ US1 ไม่ได้แสดง `sectionNo` การส่งออกภาพของ US5 ถ่ายตามหน้าจอถูกต้อง |
| แจ้ง | เจ้าของงาน US1-T07 (หน้าตาราง) และ US5-T07 |

## หมายเหตุ

- **ผู้ทดสอบ:** UAT กำหนดให้เป็นสมาชิกที่ไม่ได้พัฒนา US5 รอบนี้รันโดยเจ้าของ US5 (Wongsakorn) แบบอัตโนมัติตามขั้นใน UAT พร้อมเก็บหลักฐานทุกขั้น
- **ขั้นลบวิชา (UAT-US5-03 ขั้น 3):** ปุ่ม "ลบวิชา" บนหน้าเว็บยังปิดไว้รอ US2-T07 จึงลบผ่าน API ของ US2-T08 ที่ merge แล้ว ควรรันขั้นนี้ซ้ำผ่านหน้าเว็บหลัง US2-T07 merge
- **ปุ่ม "ไปยัง REG-TU":** UAT ตรวจว่าไม่อยู่ในภาพ หน้าเว็บตอนนี้ยังไม่มีปุ่มนี้ จึงไม่ปรากฏในภาพอยู่แล้ว
- **Browser ที่สอง:** UAT ให้ทดสอบซ้ำบน Safari หรือ Firefox อย่างน้อย 1 ตัว ยังไม่ได้รัน
