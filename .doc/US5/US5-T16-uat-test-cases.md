# US5-T16 — User Acceptance Test Cases Specification

| รายการ | รายละเอียด |
|---|---|
| User Story | **US5: บันทึกตารางเรียนส่งออกเป็นภาพ** (Priority: Medium, Estimate: 1 point) |
| Task | US5-T16 Design User Acceptance Test ตาม user story details |
| ขอบเขต | ครอบคลุม Test case 1–2 ของ US5 (Conditions of Satisfaction) |
| ใช้ใน | US5-T20 รัน User Acceptance Test |

## 1. User Story

> **As a** นักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติของมหาวิทยาลัยธรรมศาสตร์ที่จัดตารางเรียนจำลองเสร็จแล้ว
> **I want to** บันทึก/ส่งออกตารางเรียนของตัวเองเป็นไฟล์ภาพ เช่น png
> **So that** เก็บภาพไว้ดูภายหลัง หรือส่งภาพให้เพื่อนดู

**Conditions of Satisfaction**
1. กดปุ่ม Export ภาพ ต้องได้ไฟล์ภาพที่มีข้อมูลตารางครบตรงกับที่แสดงบนหน้าจอ
2. ตารางที่ยังไม่มีวิชาเลย กดส่งออก ต้องได้ภาพตารางเปล่า โดยไม่เกิด error

## 2. สมมติฐาน (ยืนยันอีกครั้งเมื่อ US5-T05 ออกแบบ UI เสร็จ)

- ปุ่ม Export อยู่บนหน้าตารางเรียนจำลอง (component ตารางของ US1)
- ส่งออกฝั่ง browser จากตารางที่แสดงอยู่ ไม่มี API/DTO ใหม่ (ตาม US5-T05)
- ไฟล์ที่ได้เป็น `.png` และถูกดาวน์โหลดลงเครื่องผ่าน browser

## 4. Test Cases

### UAT-US5-01 — ส่งออกตารางที่มีวิชาเป็นภาพ ข้อมูลครบตรงกับหน้าจอ

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | US5 Test case ที่ 1 |
| Precondition | login แล้ว และตารางเรียนจำลองมีวิชาตาม "ข้อมูลทดสอบ" |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นตารางที่มีทั้ง 3 วิชาในวันและเวลาที่ถูกต้อง และเห็นปุ่ม Export |
| 2 | กดปุ่ม Export | ได้ไฟล์ `.png` ดาวน์โหลดลงเครื่อง ไม่มีข้อความ error |
| 3 | เปิดไฟล์ภาพที่ได้ | ภาพเปิดได้ตามปกติ ไม่เป็นไฟล์เสีย |
| 4 | เทียบภาพกับตารางบนหน้าจอ | ภาพมีวิชาครบทั้ง 3 วิชา แต่ละวิชาแสดง **รหัสวิชา ชื่อวิชา วัน และเวลา** ตรงกับหน้าจอ และอยู่ในช่องวัน × เวลาเดียวกับบนหน้าจอ |
| 5 | ตรวจความชัดของภาพ | อ่านตัวอักษรได้ชัดทั้งภาษาไทยและอังกฤษ ไม่มีส่วนใดของตารางถูกตัดขาด |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง

### UAT-US5-02 — ส่งออกตารางที่ยังไม่มีวิชา ต้องได้ภาพตารางเปล่าโดยไม่เกิด error

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | US5 Test case ที่ 2 |
| Precondition | login แล้ว และตารางเรียนจำลอง**ไม่มีวิชาเลย** (ถ้ามี ให้ลบออกทั้งหมดก่อนตาม US2) |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นตารางเปล่า (มีหัววันและเวลา แต่ไม่มีวิชา) และปุ่ม Export ยังกดได้ |
| 2 | กดปุ่ม Export | ได้ไฟล์ `.png` ดาวน์โหลดลงเครื่อง ไม่มีข้อความ error และหน้าเว็บไม่ค้าง |
| 3 | เปิดไฟล์ภาพที่ได้ | ภาพเปิดได้ตามปกติ เป็นตารางเปล่าที่มีหัววันและเวลาเหมือนบนหน้าจอ และไม่มีวิชาใดๆ |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง
