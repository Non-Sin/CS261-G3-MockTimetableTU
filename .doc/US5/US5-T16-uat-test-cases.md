## 1. User Story

> **As a** นักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติของมหาวิทยาลัยธรรมศาสตร์ที่จัดตารางเรียนจำลองเสร็จแล้ว
> **I want to** บันทึก/ส่งออกตารางเรียนของตัวเองเป็นไฟล์ภาพ เช่น png
> **So that** เก็บภาพไว้ดูภายหลัง หรือส่งภาพให้เพื่อนดู

**Conditions of Satisfaction**
1. กดปุ่ม Export ภาพ ต้องได้ไฟล์ภาพที่มีข้อมูลตารางครบตรงกับที่แสดงบนหน้าจอ
2. ตารางที่ยังไม่มีวิชาเลย กดส่งออก ต้องได้ภาพตารางเปล่า โดยไม่เกิด error

## 2. ข้อตกลงที่ใช้ทดสอบ (ตาม US5-T05)

- ปุ่ม Export คือปุ่ม "⬇ PNG" ที่หัวกล่อง "ตารางเรียนจำลอง" ข้างปุ่ม "ไปยัง REG-TU" (component ตารางของ US1)
- ส่งออกฝั่ง browser จากตารางที่แสดงอยู่ ไม่มี API/DTO ใหม่
- ไฟล์ที่ได้เป็น `.png` ชื่อ `timetable-{ปีการศึกษา}-{ภาคเรียน}.png` เช่น `timetable-2568-1.png` และถูกดาวน์โหลดลงเครื่องผ่าน browser
- ภาพมีเฉพาะกล่อง "ตารางเรียนจำลอง" ไม่มีปุ่ม PNG / "ไปยัง REG-TU" แถบเตือนเวลาชน หรือส่วนค้นหารายวิชา
- **ตารางที่มีเวลาชนบันทึกเป็นภาพไม่ได้** ปุ่ม PNG ยังแสดงแต่เป็น disabled ไม่ดาวน์โหลดไฟล์ และไม่ถือเป็น error ผู้ใช้ต้องแก้เวลาชนก่อนจึงจะบันทึกภาพได้

## 4. Test Cases

### UAT-US5-01 — ส่งออกตารางที่มีวิชาเป็นภาพ ข้อมูลครบตรงกับหน้าจอ

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | US5 Test case ที่ 1 |
| Precondition | login แล้ว และตารางเรียนจำลองมีวิชาตาม "ข้อมูลทดสอบ (ตารางที่มีวิชา)" |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นตารางที่มีทั้ง 3 วิชาในวันและเวลาที่ถูกต้อง ไม่มีแถบเตือนเวลาชน และเห็นปุ่ม PNG ที่กดได้ |
| 2 | กดปุ่ม PNG | ได้ไฟล์ `timetable-2568-1.png` ดาวน์โหลดลงเครื่อง ไม่มีข้อความ error |
| 3 | เปิดไฟล์ภาพที่ได้ | ภาพเปิดได้ตามปกติ ไม่เป็นไฟล์เสีย |
| 4 | เทียบภาพกับตารางบนหน้าจอ | ภาพมีวิชาครบทั้ง 3 วิชา แต่ละบล็อกวิชาแสดง **รหัสวิชา Sec เวลา และห้อง** ตรงกับหน้าจอ อยู่ในช่องวัน × เวลาเดียวกับบนหน้าจอ แถบสรุป "วิชาในตารางเรียน" ตรงกับหน้าจอ (3 วิชา 9 หน่วยกิต) และในภาพไม่มีปุ่ม PNG / "ไปยัง REG-TU" |
| 5 | ตรวจความชัดของภาพ | อ่านตัวอักษรได้ชัดทั้งภาษาไทยและอังกฤษ ไม่มีส่วนใดของตารางถูกตัดขาด |
| 6 | ทำขั้น 2–5 ซ้ำบนหน้าจอแคบ (มือถือ หรือย่อหน้าต่าง browser จนตารางต้องเลื่อนแนวนอน) | ภาพยังมีตารางครบทุกวันและทุกช่วงเวลา ไม่ถูกตัดตามขนาดหน้าจอ |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง

### UAT-US5-02 — ส่งออกตารางที่ยังไม่มีวิชา ต้องได้ภาพตารางเปล่าโดยไม่เกิด error

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | US5 Test case ที่ 2 |
| Precondition | login แล้ว และตารางเรียนจำลอง**ไม่มีวิชาเลย** (ถ้ามี ให้ลบออกทั้งหมดก่อนตาม US2) |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นตารางเปล่า (มีหัววันและเวลา แต่ไม่มีวิชา) และปุ่ม PNG ยังกดได้ |
| 2 | กดปุ่ม PNG | ได้ไฟล์ `timetable-2568-1.png` ดาวน์โหลดลงเครื่อง ไม่มีข้อความ error และหน้าเว็บไม่ค้าง |
| 3 | เปิดไฟล์ภาพที่ได้ | ภาพเปิดได้ตามปกติ เป็นตารางเปล่าที่มีหัววันและเวลาเหมือนบนหน้าจอ และไม่มีวิชาใดๆ |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง

### UAT-US5-03 — ตารางที่มีเวลาชน ไม่สามารถบันทึกเป็นภาพได้

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | ข้อตกลงเรื่องเวลาชนใน US5-T05 (ปุ่ม PNG disabled เมื่อ `conflicts` ไม่ว่าง) |
| Precondition | login แล้ว และตารางเรียนจำลองมีวิชาตาม "ข้อมูลทดสอบ (ตารางที่มีวิชา)" และ "ข้อมูลทดสอบ (ตารางที่มีเวลาชน)" รวม 4 วิชา |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นแถบเตือน "ตรวจพบเวลาเรียนซ้อนทับกัน" ระบุ LAS101 และ TU109 วันพุธ 09:30–12:30 และเห็นปุ่ม PNG ที่หัวกล่องตาราง |
| 2 | ตรวจปุ่ม PNG แล้วลองกด | ปุ่มอยู่ในสถานะ disabled กดไม่ได้ ไม่มีไฟล์ดาวน์โหลด และไม่มีข้อความ error |
| 3 | ลบ TU109 ออกจากตาราง (ตาม US2) | แถบเตือนเวลาชนหายไป และปุ่ม PNG กลับมากดได้ |
| 4 | กดปุ่ม PNG แล้วเปิดไฟล์ภาพ | ได้ไฟล์ `timetable-2568-1.png` ที่มีวิชาครบ 3 วิชาตรงกับหน้าจอ ไม่มี TU109 |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง
