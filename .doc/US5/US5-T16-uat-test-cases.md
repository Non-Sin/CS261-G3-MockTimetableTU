# US5-T16 — User Acceptance Test Cases Specification

| รายการ | รายละเอียด |
|---|---|
| User Story | **US5: บันทึกตารางเรียนส่งออกเป็นภาพ** (Priority: Medium, Estimate: 1 point) |
| Task | US5-T16 Design User Acceptance Test ตาม user story details |
| ขอบเขต | ครอบคลุม Test case 1–2 ของ US5 (Conditions of Satisfaction) และข้อสรุปการประชุมทีมเรื่องตารางที่มีเวลาชน |
| ใช้ใน | US5-T20 รัน User Acceptance Test |

## 1. User Story

> **As a** นักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติของมหาวิทยาลัยธรรมศาสตร์ที่จัดตารางเรียนจำลองเสร็จแล้ว
> **I want to** บันทึก/ส่งออกตารางเรียนของตัวเองเป็นไฟล์ภาพ เช่น png
> **So that** เก็บภาพไว้ดูภายหลัง หรือส่งภาพให้เพื่อนดู

**Conditions of Satisfaction**
1. กดปุ่ม Export ภาพ ต้องได้ไฟล์ภาพที่มีข้อมูลตารางครบตรงกับที่แสดงบนหน้าจอ
2. ตารางที่ยังไม่มีวิชาเลย กดส่งออก ต้องได้ภาพตารางเปล่า โดยไม่เกิด error

## 2. ข้อตกลงที่ใช้ทดสอบ (ตาม US5-T05)

- ปุ่ม Export คือปุ่ม "PNG" ที่หัวกล่อง "ตารางเรียนจำลอง" บนหน้าตารางเรียนจำลอง (component ตารางของ US1)
- ส่งออกฝั่ง browser จากตารางที่แสดงอยู่ ไม่มี API/DTO ใหม่ (ตาม [US5-T05](./T05/US5-DTO%20&%20API%20Spec.md))
- ไฟล์ที่ได้เป็น `.png` ชื่อ `timetable-{ปีการศึกษา}-{ภาคเรียน}.png` เช่น `timetable-2569-2.png` และถูกดาวน์โหลดลงเครื่องผ่าน browser
- ภาพมีเฉพาะกล่อง "ตารางเรียนจำลอง" ไม่มีปุ่มต่าง ๆ แถบเตือนเวลาชน หรือส่วนค้นหารายวิชา
- ตามข้อสรุปการประชุมทีม: การแจ้งเตือนบนหน้าเว็บมีเฉพาะเวลาชน และ**ตารางที่มีเวลาชนไม่สามารถบันทึกเป็นภาพได้** ปุ่ม PNG ยังแสดงแต่กดไม่ได้

| CS180 | 820001 | จันทร์ | 13:30–16:30 | LC5-S202 |
| MA211 | 020001 | อังคาร, พฤหัสบดี | 09:30–11:00 | SC-3015 |
| CS111 | 030001 | อังคาร, พฤหัสบดี | 11:00–12:30 | LC3-121 |

## 4. Test Cases

### UAT-US5-01 — ส่งออกตารางที่มีวิชาเป็นภาพ ข้อมูลครบตรงกับหน้าจอ

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | US5 Test case ที่ 1 |
| Precondition | login แล้ว และตารางเรียนจำลองมีวิชาตาม "ข้อมูลทดสอบ" |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นตารางที่มีทั้ง 3 วิชาในวันและเวลาที่ถูกต้อง ไม่มีแถบเตือนเวลาชน และเห็นปุ่ม PNG ที่กดได้ |
| 2 | กดปุ่ม PNG | ได้ไฟล์ `timetable-2569-2.png` ดาวน์โหลดลงเครื่อง ไม่มีข้อความ error |
| 3 | เปิดไฟล์ภาพที่ได้ | ภาพเปิดได้ตามปกติ ไม่เป็นไฟล์เสีย |
| 4 | เทียบภาพกับตารางบนหน้าจอ | ภาพมีวิชาครบทั้ง 3 วิชา แต่ละบล็อกวิชาแสดง **รหัสวิชา เวลา และห้อง** ตรงกับหน้าจอ อยู่ในช่องวัน × เวลาเดียวกับบนหน้าจอ และแถบสรุปขึ้น "3 วิชา (9.0 หน่วยกิต)" ในภาพไม่มีปุ่ม PNG |
| 5 | ตรวจความชัดของภาพ | อ่านตัวอักษรได้ชัดทั้งภาษาไทยและอังกฤษ ไม่มีส่วนใดของตารางถูกตัดขาด |
| 6 | ทำขั้น 2–5 ซ้ำบนหน้าจอมือถือ (หรือย่อหน้าต่าง browser ให้แคบจนตารางต้องเลื่อนแนวนอน) | ภาพยังมีตารางครบทุกช่วงเวลา ไม่ถูกตัดตามขนาดหน้าจอ |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง

### UAT-US5-02 — ส่งออกตารางที่ยังไม่มีวิชา ต้องได้ภาพตารางเปล่าโดยไม่เกิด error

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | US5 Test case ที่ 2 |
| Precondition | login แล้ว และตารางเรียนจำลอง**ไม่มีวิชาเลย** (ถ้ามี ให้ลบออกทั้งหมดก่อนตาม US2) |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นตารางเปล่า (มีหัววันและเวลา แต่ไม่มีวิชา) และปุ่ม PNG ยังกดได้ |
| 2 | กดปุ่ม PNG | ได้ไฟล์ `timetable-2569-2.png` ดาวน์โหลดลงเครื่อง ไม่มีข้อความ error และหน้าเว็บไม่ค้าง |
| 3 | เปิดไฟล์ภาพที่ได้ | ภาพเปิดได้ตามปกติ เป็นตารางเปล่าที่มีหัววันและเวลาเหมือนบนหน้าจอ และไม่มีวิชาใดๆ |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง

### UAT-US5-03 — ตารางที่มีเวลาชน ไม่สามารถบันทึกเป็นภาพได้

| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | ข้อสรุปการประชุมทีม (ปุ่มบันทึกรูปกดไม่ได้หากตารางมีวิชาที่เวลาชนกัน) |
| Precondition | login แล้ว และตารางเรียนจำลองมีวิชาตาม "ข้อมูลทดสอบ (ตารางที่มีเวลาชน)" |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้าตารางเรียนจำลอง | เห็นแถบเตือน "ตรวจพบเวลาเรียนซ้อนทับกัน" ระบุ LAS101 และ TU109 วันพุธ 09:30–12:30 และเห็นปุ่ม PNG ที่หัวกล่องตาราง |
| 2 | ตรวจปุ่ม PNG แล้วลองกด | ปุ่มเป็นสีเทาและกดไม่ได้ ไม่มีไฟล์ดาวน์โหลด และไม่มีข้อความ error |
| 3 | ลบ TU109 ออกจากตาราง (ตาม US2) | แถบเตือนเวลาชนหายไป และปุ่ม PNG กลับมากดได้ |
| 4 | กดปุ่ม PNG | ได้ไฟล์ `timetable-2569-2.png` ที่มีวิชาครบตามหน้าจอ |

**เกณฑ์ผ่าน:** ทุกขั้นได้ผลตามที่คาดหวัง
