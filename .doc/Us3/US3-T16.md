| Task | US3-T16 Design User Acceptance Test ตาม user story details |

## 1. User Story

> As a นักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติของมหาวิทยาลัยธรรมศาสตร์ ที่มี user name และ password ที่เข้าสู่ระบบของสำนักทะเบียน I want to เข้าสู่ระบบช่วยวางแผนตารางเรียนด้วย user name และ password เดียวกับที่เข้าสู่ระบบของสำนักทะเบียน So that
> 1. สามารถยืนยันตัวตนเข้าใช้งานระบบเพื่อวางแผนตารางเรียนได้อย่างสะดวกรวดเร็ว
> 2. ระบบสามารถยืนยันสถานะความเป็นนักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติ และเตรียมพื้นที่จัดเก็บข้อมูลแผนการเรียนรวมถึงรายการวิชาที่สอบผ่านของผู้ใช้ในระบบได้อย่างถูกต้องและปลอดภัย

**Test cases**

1. Login ด้วย user name และ password ของนักศึกษา มธ. ที่ยังมี user account active ต้องเข้าสู่ระบบได้สำเร็จ
2. Login ด้วย user name และ password ของนักศึกษา มธ. ที่มี user account ไม่ active แล้ว ต้องไม่สามารถเข้าสู่ระบบได้
3. Login ด้วย Username และ Password ของนักศึกษาที่ไม่ใช่สาขาวิทยาการคอมพิวเตอร์ภาคปกติ ระบบต้องไม่อนุญาตให้เข้าสู่ระบบ และแสดงข้อความแจ้งเตือนว่าระบบนี้เปิดให้ใช้งานเฉพาะนักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติเท่านั้น
4. หลังจากเปลี่ยนรหัสผ่านของ account มธ. ผ่านช่องทางใดๆ เมื่อทดสอบ login ด้วย user name และรหัสผ่านใหม่ ต้องเข้าสู่ระบบได้สำเร็จ
5. หลังจากเปลี่ยนรหัสผ่านของ account มธ. ผ่านช่องทางใดๆ เมื่อทดสอบ login ด้วย user name และรหัสผ่านเดิม ต้องไม่สามารถเข้าสู่ระบบได้
6. Login ด้วย user name หรือ password ที่ไม่ถูกต้อง ระบบต้องแจ้งเตือนข้อผิดพลาด และไม่อนุญาตให้เข้าสู่ระบบ
7. Login ด้วย user name หรือ password ที่ไม่ถูกต้องติดต่อกันเกิน 5 ครั้ง ระบบต้องระงับการเข้าสู่ระบบของบัญชีดังกล่าวชั่วคราวเป็นเวลา 15 นาที และแสดงข้อความแจ้งเตือนระยะเวลาที่ต้องรอก่อนลองใหม่อีกครั้ง
8. หลังจาก login สำเร็จเป็นครั้งแรก ระบบต้องให้ผู้ใช้งานกรอกประวัติส่วนตัว
9. หลังจาก login สำเร็จ ตั้งแต่ครั้งที่ 2 เป็นต้นไป ระบบต้องแสดงชื่อ-นามสกุล และรหัสนักศึกษาของผู้ที่ login สำเร็จ และแสดงเมนูให้นักศึกษาที่สามารถทำฟังก์ชันต่อไปนี้ได้ ได้แก่ เพิ่ม/ลดวิชา และเปลี่ยนกลุ่มเรียน ในตารางเรียนจำลอง, ตรวจสอบเงื่อนไขรายวิชา, บันทึกวิชาที่เคยเรียนผ่าน, ดูวิชาเสริมแนะนำ และค้นหาช่องทางขอโควตา

## 3. Test Cases

| TC | Account | Precondition | ขั้นตอน | ผลที่คาดหวัง |
|---|---|---|---|---|
| 1 | A | account มธ. active, เป็นนักศึกษา CS ภาคปกติ | กรอก username/password ถูกต้อง แล้วกด login | เข้าสู่ระบบได้สำเร็จ |
| 2 | B | account มธ. ไม่ active | กรอก username/password แล้วกด login | เข้าสู่ระบบไม่ได้ |
| 3 | C | นักศึกษาไม่ใช่สาขา CS ภาคปกติ | กรอก username/password แล้วกด login | เข้าสู่ระบบไม่ได้ และแสดงข้อความแจ้งว่าเปิดให้เฉพาะนักศึกษา CS ภาคปกติ |
| 4 | A | เปลี่ยนรหัสผ่าน มธ. แล้ว (ช่องทางใดก็ได้) | login ด้วย username + รหัสผ่านใหม่ | เข้าสู่ระบบได้สำเร็จ |
| 5 | A | เปลี่ยนรหัสผ่าน มธ. แล้ว | login ด้วย username + รหัสผ่านเดิม | เข้าสู่ระบบไม่ได้ |
| 6 | A | - | login ด้วย username หรือ password ที่ไม่ถูกต้อง | แจ้งข้อผิดพลาด และไม่อนุญาตให้เข้าสู่ระบบ |
| 7 | D | account ที่ยังไม่เคยถูกล็อก | กรอก username หรือ password ผิดติดต่อกันเกิน 5 ครั้ง | ระงับการเข้าสู่ระบบ 15 นาที และแสดงระยะเวลาที่ต้องรอก่อนลองใหม่ |
| 8 | E | login ครั้งแรกของ account | login สำเร็จ | ระบบให้ผู้ใช้งานกรอกประวัติส่วนตัว |
| 9 | F | เคย login และกรอกประวัติแล้ว (ครั้งที่ 2 ขึ้นไป) | login สำเร็จ | แสดงชื่อ-นามสกุลและรหัสนักศึกษา พร้อมเมนู: เพิ่ม/ลดวิชา, เปลี่ยนกลุ่มเรียน, ตรวจสอบเงื่อนไขรายวิชา, บันทึกวิชาที่เคยเรียนผ่าน, ดูวิชาเสริมแนะนำ, ค้นหาช่องทางขอโควตา |

## 4. Test Execution Results

| TC | Test Result | หมายเหตุ |
|---|---|---|
| 1 | Not Run | ตรวจสอบการ Login ด้วย Account ที่ Active |
| 2 | Not Run | ตรวจสอบการ Login ด้วย Account ที่ไม่ Active |
| 3 | Not Run | ตรวจสอบการ Login ของนักศึกษาต่างสาขา |
| 4 | Not Run | ตรวจสอบการ Login ด้วยรหัสผ่านใหม่หลังเปลี่ยนรหัสผ่าน |
| 5 | Not Run | ตรวจสอบว่ารหัสผ่านเดิมไม่สามารถ Login ได้หลังเปลี่ยนรหัสผ่าน |
| 6 | Not Run | ตรวจสอบการแจ้งเตือนเมื่อกรอก Username หรือ Password ไม่ถูกต้อง |
| 7 | Not Run | ตรวจสอบการระงับการ Login 15 นาทีหลังกรอกข้อมูลผิดติดต่อกันเกิน 5 ครั้ง |
| 8 | Not Run | ตรวจสอบการกรอกประวัติส่วนตัวเมื่อ Login ครั้งแรก |
| 9 | Not Run | ตรวจสอบการแสดงข้อมูลนักศึกษาและเมนูการใช้งานหลัง Login |

**หมายเหตุ**
- `Pass` — ผลการทดสอบตรงตามที่คาดหวัง
- `Fail` — ผลการทดสอบไม่ตรงตามที่คาดหวัง
- `Not Run` — ยังไม่ได้ทดสอบ
