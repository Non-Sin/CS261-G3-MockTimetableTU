### สิ่งที่ปรับจาก US8-T15

1. **ตาราง `study_minor_course` มีคอลัมน์ `plan_type` (NOT NULL)** ตาม migration ของ US8-T09 ส่วน insert วิชาโทในสคริปต์ของ T15 จึงไม่ผ่าน ใส่วิชาโทเดิม (JP171, LAS101 / CS180 / TU106) ให้ทั้ง `SPECIAL_PROJECT` และ `CO_OP` ด้วย [st-us8-minor-courses.sql](./evidence/st-us8-minor-courses.sql)
2. **ล้างตารางด้วย API ของ US2** (`DELETE /api/timetable/entries?entryIds=...` เท่ากับกด "ลบทั้งหมด") แทน SQL DELETE แถว `timetable` จึงยังอยู่ (entries ว่าง) และจัดลำดับให้ข้อที่ต้องตรวจว่า "ยังไม่มีตาราง" (16, 05, 06, 12, 14) รันตอนที่นักศึกษายังไม่เคยมีตารางของภาคนั้นจริง ลำดับที่รัน: 16, 01–07, 15, 12, 14, 08, 09, 10, 11, 13
3. **หน้าเว็บแสดงสรุปอัตโนมัติ** ตามที่ทีมตกลงใน US8-T11 ไม่มีปุ่ม "ดูสรุป" ขั้นที่เขียนว่ากด "ดูสรุป" จึงเป็นการเลือกชั้นปี/ภาค/หลักสูตรแล้วรอรายการสรุป และปุ่มยืนยันชื่อ "เพิ่มลงตารางเรียน"
4. **US8-T09 seed แผนจริงแล้ว** ข้อ 01 และ 03 ตรวจเฉพาะแผนที่ชื่อหลักสูตรขึ้นต้นด้วย "หลักสูตรทดสอบ ST-" ตามข้อจำกัดใน T15 ข้อ 02 ใช้ชั้นปีที่ 4 ภาค 2 ได้ตามเดิม เพราะแผนจริงไม่มีชั้นปีนี้
