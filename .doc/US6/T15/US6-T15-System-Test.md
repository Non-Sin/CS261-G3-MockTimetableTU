# US6-T15 Design System Test ตาม Sequence Diagram

## User story
US6: ระบบแนะนำวิชาเสรี

**Conditions of Satisfaction** (จากการ์ด US6)
1. นักศึกษาสามารถดูเมนู แนะนำวิชาเสรี ได้
2. ระบบแสดงรายการวิชาเสรีที่สามารถลงทะเบียนได้
3. ระบบแสดงข้อมูลของวิชา เช่น ชื่อวิชา รายละเอียด และหน่วยกิต

## Objective
ออกแบบ System Test ของหน้า "ดูวิชาเสรีแนะนำ" ตั้งแต่หน้าเว็บ → API → ฐานข้อมูล ให้ครอบคลุมทุกเส้นทางใน Sequence Diagram ทั้ง 3 ไฟล์ของ US6-T06 (PR #92 ฉบับ `f2c69b5`) ได้แก่ ค้นหาและกรองวิชาเสรี, เปิดรายละเอียดและรีวิว และเพิ่มวิชาเสรีลงตาราง และใช้ใน US6-T19 (รัน System Test)

เขียนจาก US6-T06 ฉบับที่ approve แล้วแต่ยังรอ merge ถ้าแผนภาพเปลี่ยนต้องแก้เคสตาม ส่วน Spec ใช้ [US6-T05 DTO & API Spec](../T05/US6-DTO%20&%20API%20Spec.md) ที่ merge แล้ว และข้อตกลงจากรีวิว PR #91 (US6-T13) ซึ่ง US6-T06 ปรับตามแล้ว: modal เลือก Sec แรกที่ `selectable` และยังไม่ `inTimetable` ให้เสมอ (เรียงตาม `semester` แล้ว `sectionNo`) ถ้าไม่มี Sec ที่เลือกได้จะไม่เลือกและปุ่มเพิ่ม disabled, `conflictWith` ไม่นับวิชาเดียวกัน, โหลดข้อมูลไม่สำเร็จแสดง "ไม่สามารถโหลดข้อมูลวิชาได้ กรุณาลองใหม่อีกครั้ง"

## Scope
ทดสอบ `GET /api/electives`, `GET /api/electives/{courseCode}` และ `POST /api/timetable/entries` (US1) ทั้งระบบที่รันจริงใน Docker และตรวจตารางด้วย `GET /api/timetable` ของ US1

## Test Approach
- System Test ใช้ระบบจริงทั้งชุด ไม่ mock: หน้าเว็บ (Next.js) + backend (Spring Boot) + SQL Server รันด้วย `docker compose up -d --build` ตาม README ตั้ง `SPRING_PROFILES_ACTIVE=stub-tu` ใน `.env`
- **ข้อมูลวิชาเสรีทั้งหมดเป็นข้อมูลจริงจากชีต "เสรี" ของ [sheet ข้อมูลของทีม](https://docs.google.com/spreadsheets/d/1OGlBEta-Qrl1A0p4MWngh4PlCRBNDEyHinQqgSsRZ6k/edit?usp=sharing)** ครบ 18 วิชาตามที่ US6-T09 ต้อง seed (ตาราง `elective_info`, `elective_tag`, `elective_review_point` ตาม ER Diagram ของ US6-T06) ไม่มีวิชาหรือเวลาที่สร้างขึ้นเอง
- ตารางตั้งต้นของทุกเคสใช้**วิชาเสรีด้วยกันเอง** (เพิ่มผ่าน modal ของ US6 หรือ `POST /api/timetable/entries`) จึงต้องการแค่ seed ของ US6 ไม่ขึ้นกับ seed รายวิชาอื่นของ US1 ซึ่งยังไม่ตรงกับข้อมูลจริง
- ผลที่คาดหวังของตัวกรองและเวลาชนทุกข้อคำนวณกับทั้ง 18 วิชาด้วยสคริปต์ตามกติกาใน Spec และ Sequence Diagram ค้นหาก่อนเขียน
- ผู้ใช้คือบัญชี stub `6609000001` รหัสผ่าน `Passw0rd!` (นักศึกษาวิทยาการคอมพิวเตอร์ภาคปกติ) ตารางปัจจุบันคือปีการศึกษา 2568 ภาคเรียน 1 (ค่าเริ่มต้นของหน้าตาราง) ยกเว้นที่ระบุ
- ตรวจผล 3 ชั้นในทุก test case: หน้าเว็บ, API response (DevTools แท็บ Network หรือ Postman) และข้อมูลใน DB
- กรณีที่ทำผ่านหน้าเว็บไม่ได้ (ST-US6-14, 15) ให้ยิง API ตรงด้วย Postman หรือ `curl` พร้อม token
- Test case แต่ละข้อเริ่มจากล้างตารางของนักศึกษาทดสอบ แล้วเตรียมตารางตาม Preconditions ลำดับการรันจึงไม่มีผล
- ยังไม่ได้ดำเนินการทดสอบจริง เพราะ US6-T07 ถึง T10 ยังไม่ได้พัฒนา ข้อความบนหน้าเว็บอาจปรับตาม Implementation จริง

### 1. ตรวจ seed ก่อนเริ่ม (รันครั้งเดียว)

ต้องได้ 18 แถว ทุกวิชาเป็น `FREE_ELECTIVE` และมีรีวิวอย่างน้อย 1 ข้อ ถ้าไม่ครบให้แจ้งเจ้าของ US6-T09 ก่อน ไม่เริ่มทดสอบ

```sql
SELECT i.course_code, c.category, i.interest_group, i.requires_quota,
       (SELECT COUNT(*) FROM elective_review_point r WHERE r.course_code = i.course_code) AS reviews,
       (SELECT COUNT(DISTINCT s.semester) FROM section s WHERE s.course_code = i.course_code AND s.academic_year = 2568) AS terms
FROM elective_info i JOIN course c ON c.course_code = i.course_code
ORDER BY i.interest_group, i.course_code;
```

## Test Cases

### [ST-US6-01] เปิดเมนูแล้วเห็นวิชาเสรีแนะนำทั้งหมด

**Related CoS:** Test Case 1, Test Case 2

**เส้นทาง:** ค้นหา → token ถูกต้อง → ภาคเรียนถูกต้อง → ไม่เปิด toggle (ไม่โหลดตาราง) → metadata query → section query → 200

**Preconditions:**
- ตรวจ seed ผ่าน · ล้างตารางแล้ว (T-EMPTY) · login ด้วย `6609000001`

**Test Steps:**

2. ตรวจหน้าเว็บ, request/response ใน DevTools และ DB

**Expected Result:**
- API: request เป็น `GET /api/electives?academicYear=2568&currentSemester=1` ไม่มีตัวกรองอื่น (`excludeConflicts` ไม่ส่งหรือเป็น `false`) พร้อม `Authorization: Bearer` · ตอบ `200` ได้ 18 วิชาตามลำดับในหัวข้อ 2 (EG214, FR205, TH291, PY200, PY250, PY252, PY320, AN242, AN347, AS201, GE225, PB317, AT326, FD216, IS313, PC280, JC217, RE468)
