## 1. User Story

**As a** นักศึกษาสาขาวิทยาการคอมพิวเตอร์ภาคปกติของมหาวิทยาลัยธรรมศาสตร์ที่กำลังจัดตารางเรียน
**I want to** ดูวิชาเสรีที่แนะนำพร้อมรีวิวจากรุ่นพี่ และเพิ่มลงตารางเรียนจำลองได้ทันที
**So that** เลือกวิชาเสรีที่เหมาะกับตัวเองและไม่ชนกับตารางเรียนปัจจุบันได้อย่างสะดวก

**Conditions of Satisfaction** (อ้างอิงจาก US6)
1. นักศึกษาสามารถดูเมนู แนะนำวิชาเสรี ได้
2. ระบบแสดงรายการวิชาเสรีที่สามารถลงทะเบียนได้
3. ระบบแสดงข้อมูลของวิชา เช่น ชื่อวิชา รายละเอียด และหน่วยกิต

Test case ข้อ 4 เป็นต้นไปด้านล่างเป็นกรณีที่ออกแบบไว้ใน API Spec และ UI Prototype ของ US6-T05 แต่ยังไม่อยู่ใน CoS 3 ข้อ ระบุในคอลัมน์อ้างอิงว่า "ตาม T05"

## 2. ข้อตกลงที่ใช้ทดสอบ

- เมนู "ดูวิชาเสรีแนะนำ" อยู่ในเมนูหลักของระบบ เปิดแล้วเห็นรายการวิชาเสรีทันทีโดยยังไม่ได้ใส่ตัวกรอง
- ตัวกรองทำงานร่วมกันได้ ผลลัพธ์ต้องสอดคล้องกับทุกเงื่อนไขที่เลือกอยู่ (วิชาแสดงเมื่อมี Sec เดียวกันที่ผ่านทุกเงื่อนไขพร้อมกัน)
- ช่วงเวลาในตัวกรอง: เช้า (08:00 - 12:30), บ่าย (13:30 - 16:30), เย็น (16:30 - 19:30)
- วิชาในหน้านี้ดูได้ทั้งปีการศึกษา แต่เพิ่มลงตารางได้เฉพาะ Sec ที่อยู่ภาคเรียนเดียวกับตารางปัจจุบัน
- กติกาของ US1 ที่ใช้เมื่อเพิ่มวิชา: หน่วยกิตรวมไม่เกิน 22 และ 1 วิชาเพิ่มได้เพียง 1 กลุ่มเรียน เวลาชนไม่ block การเพิ่ม

### UAT-US6-10: เวลาชนแจ้งเตือนแต่ยังเพิ่มได้
| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | ตาม T05 (ใช้กติกาของ US1) |
| Precondition | ตารางเรียนจำลองเป็นตาม D5 |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิด modal ของ D1 (PY250) | ใต้ Sec 820001 แสดงข้อความเตือนว่า "ชนกับ" รหัสวิชาที่อยู่ในตาราง |
| 2 | กด "+ เพิ่มลงตาราง" | เพิ่มวิชาได้ (ไม่ถูกบล็อก) |
| 3 | ตรวจตารางเรียนจำลอง | วิชาทั้งสองแสดงเวลาชน พร้อมแจ้งเตือนเวลาเรียนซ้อนทับตามที่ US1 กำหนด |

**เกณฑ์ผ่าน:** เวลาชนเป็นแค่คำเตือน ไม่ปฏิเสธการเพิ่ม

### UAT-US6-11: เพิ่มไม่ได้เมื่อหน่วยกิตเกินหรือวิชาซ้ำ
| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | ตาม T05 (ใช้กติกาของ US1) |
| Precondition | (ก) ตารางเรียนจำลองเป็นตาม D6 (21 หน่วยกิต) (ข) ตารางมี PY250 Sec 820001 อยู่แล้ว |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| ก-1 | เปิด modal ของ PY250 แล้วกด "+ เพิ่มลงตาราง" | ไม่เพิ่มวิชา และแสดงเหตุผลใน modal เช่น "เพิ่ม PY250 (3 หน่วยกิต) แล้วจะเป็น 24 หน่วยกิต เกินกำหนด 22 หน่วยกิต" |
| ก-2 | ตรวจตารางเรียนจำลอง | ตารางและหน่วยกิตรวมเท่าเดิม |
| ข-1 | (กรณีข้อมูลบนจอเก่า เช่น เพิ่ม PY250 จากอีกแท็บไปแล้ว) กด "+ เพิ่มลงตาราง" ในหน้าที่ยังไม่รีเฟรช | ไม่เพิ่มวิชา และแสดงเหตุผลว่า PY250 อยู่ในตารางแล้ว (1 วิชาเพิ่มได้ 1 กลุ่มเรียน) |

**เกณฑ์ผ่าน:** ทั้งสองกรณีไม่เพิ่มวิชา แจ้งเหตุผลชัดเจนใน modal และตารางไม่เปลี่ยน

### UAT-US6-12: วิชาที่ต้องขอโควตา
| รายการ | รายละเอียด |
|---|---|
| อ้างอิง | ตาม T05 |
| Precondition | อยู่ที่หน้าแนะนำวิชาเสรี |

| ขั้น | การกระทำ | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิด modal ของ D2 (FR205) | แสดงป้าย "รายวิชาที่ต้องขอโควตา" และปุ่ม "ค้นหาช่องทางขอโควตา" |
| 2 | กดปุ่ม "ค้นหาช่องทางขอโควตา" | พาไปเมนูค้นหาช่องทางขอโควตา (US7) |
| 3 | เปิด modal ของ D1 (PY250) | **ไม่มี** ป้ายหรือปุ่มเกี่ยวกับโควตา เพราะไม่ต้องขอโควตา |

**เกณฑ์ผ่าน:** วิชาที่ต้องขอโควตาแสดงป้ายและปุ่มพาไปเมนูขอโควตา วิชาที่ไม่ต้องขอไม่แสดง
