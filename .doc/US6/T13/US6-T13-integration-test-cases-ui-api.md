## 1. แนวทางและสภาพแวดล้อม

Integration test ระหว่าง UI กับ API ตรวจว่าหน้าเว็บกับ backend คุยกันถูกต้องจริง ไม่ใช่แค่ component ทำงานได้ตามที่จำลอง (US6-T11) หรือ API ตอบถูกเมื่อยิงตรง (US6-T14) แต่ละเคสตรวจ 3 ชั้นต่อกัน:

1. **สิ่งที่ UI ส่ง** (method, path, query string, body, header `Authorization`)
2. **สิ่งที่ API ตอบ** (status, body หรือ ProblemDetail)
3. **สิ่งที่ UI แสดงหลังรับคำตอบ** (การ์ด, หัวข้อหมวด, จำนวนวิชา, modal, ข้อความ, การเรียก API ต่อ)

| รายการ | ข้อกำหนด |
| --- | --- |
| ระบบ | รัน frontend + backend + SQL Server จริงด้วย `docker compose up -d --build` ตั้ง `SPRING_PROFILES_ACTIVE=stub-tu` ใน `.env` |
| ผู้ใช้ | บัญชี stub `6609000001` รหัสผ่าน `Passw0rd!` (นักศึกษาวิทยาการคอมพิวเตอร์ภาคปกติ) |

| เครื่องมือ | เบราว์เซอร์ + DevTools แท็บ Network ตรวจ request/response · Postman หรือ `curl` สำหรับเคสสัญญา API (หัวข้อ 5.3) · DevTools "Offline" / request blocking สำหรับเคสที่สร้างจาก UI ปกติไม่ได้ |

## 2. สัญญาระหว่าง UI กับ API (สรุปจาก US6-T05)

| Endpoint | Request ที่ UI ส่ง | สำเร็จ | Error |
| --- | --- | --- | --- |
| 1 รายการวิชาเสรี | `GET /api/electives?academicYear=2568&currentSemester=1` + `q`, `semester`, `day`, `timeSlot`, `group`, `excludeConflicts` เฉพาะตัวที่เลือก | `200` `ElectiveSummaryResponse[]` (ไม่พบ = `[]`) เรียงตามหมวด (`LANGUAGE` → `PSYCHOLOGY` → `SOCIETY` → `SCIENCE` → `MEDIA`) แล้วตาม `courseCode` | `400` param ผิด · `401` ไม่มี token |
| 2 รายละเอียดวิชา | `GET /api/electives/{courseCode}?academicYear=2568&currentSemester=1` | `200` `ElectiveDetailResponse` (`description`, `sections` ทุก Sec ของทั้งปีพร้อม `selectable`, `inTimetable`, `conflictWith`) | `400` · `401` · `404` ไม่ใช่วิชาเสรีแนะนำ |
| 3 เพิ่มลงตาราง (US1) | `POST /api/timetable/entries` body `{ "sectionId": <Sec ที่เลือก> }` | `201` `TimetableResponse` (เวลาชนไม่ block มี `conflicts`) | `409` `CREDIT_LIMIT_EXCEEDED` / `COURSE_ALREADY_IN_TIMETABLE` · `401` |

กติกาที่ใช้กำหนดผลที่คาดหวัง (Spec):

- `currentSemester` คือภาคของตารางปัจจุบัน ไม่ใช่ dropdown "ภาคเรียน" ของหน้านี้ ใช้ตัดสิน `selectable` และดึงตารางมาตรวจเวลาชน
- ตัวกรองระดับ Sec (`semester`, `day`, `timeSlot`, `excludeConflicts`) ต้องผ่านพร้อมกันใน **Sec เดียวกัน** ส่วน `day` + `timeSlot` ต้องตรงใน**คาบเดียวกัน**
- `timeSlot`: คาบอยู่ในช่วงเมื่อ `startTime` อยู่ใน [from, to): `MORNING` 08:00–12:30, `AFTERNOON` 12:30–16:30, `EVENING` 16:30–21:00
- `excludeConflicts=true`: เหลือเฉพาะ Sec ของ `currentSemester` ที่ทุกคาบไม่ชนกับตารางปัจจุบัน (คาบต่อกันพอดีไม่ชน) และตัดวิชาที่อยู่ในตารางแล้ว คู่กับ `semester` ที่ไม่ใช่ `currentSemester` ได้ `[]` เสมอ
- `q` ตรงเมื่อรหัสวิชาขึ้นต้นด้วย q, ชื่ออังกฤษมีคำที่ขึ้นต้นด้วย q หรือชื่อไทยมี q อยู่ส่วนใดก็ได้ ไม่สนตัวพิมพ์
- modal: Sec ที่ `selectable: false` เป็นสีจาง กดเลือกไม่ได้ ต่อท้าย "(ตารางเรียนปัจจุบันคือภาคเรียนที่ N)" · Sec ที่ `inTimetable` แสดง "เพิ่มแล้ว" · วิชาที่มี Sec ใดอยู่ในตารางแล้ว ปุ่ม "+ เพิ่มลงตาราง" disabled และแสดง "อยู่ในตารางแล้ว" · `conflictWith` ไม่ว่าง เตือน "ชนกับ ..." แต่ยังเพิ่มได้
- หลัง `201`: ปิด modal แสดง "เพิ่ม {courseCode} Sec {sectionNo} ลงตารางแล้ว" ถ้าเปิด `excludeConflicts` อยู่ให้เรียก endpoint 1 ใหม่ · `409` แสดง `detail` ใน modal (US6 แสดงข้อความหน่วยกิตเกิน ต่างจากหน้า US1) · `401` กลับหน้า Login
